# The report

*[← CFD from Scratch](../)*

**[report.pdf](report.pdf)** — *Learning Computational Fluid Dynamics by Building
It: From One-Dimensional Advection to the Lid-Driven Cavity*, 62 pages, written
at the end of the internship at CSIR-NAL's CTFD division under
Dr. V. K. Suman.

The report is the long form of this repository. Where a module README gives the
result, the report gives the derivation, the twenty-one cavity runs behind it,
and a chapter on the mistakes. The two agree on every number; where the report
carries more, the module README says so and points here.

## The two scripts

These are the scripts that produced the report, committed unchanged. Together
they generate every figure and every number in Chapters 10–12.

### `make_all_figures.py` — all 28 figures

Four groups, and the difference between them matters:

| Group | Figures | Needs |
|---|---|---|
| `make_schematics()` | 8 | nothing |
| `make_journey()` | 8 | nothing |
| `make_overflow()` | 1 | nothing |
| `make_cavity()` | 10 | the saved cavity runs |

That is 27. The twenty-eighth, Figure 10.2, is a screenshot of the first runs
and was never generated by anything.

**Seventeen of the twenty-eight regenerate from nothing but numpy and
matplotlib** — they solve their own small problems on the spot. On an ordinary
laptop:

```bash
python3 -c "
import make_all_figures as m
m.make_schematics(); m.make_journey(); m.make_overflow()"
```

about 25 seconds, and it prints the numbers it draws as it goes:

```
f=2:  max|u| for x<8.5 = 0.8373      <- 100 points per wavelength
f=10: max|u| for x<8.5 = 0.0120      <-  20 points per wavelength
f=50: max|u| for x<8.5 = 0.0000      <-   4 points per wavelength
FTCS: final max|u|=2.950e+49
201^2: step 0 error 240.0 ; steps until non-finite: 18
```

Those are Figure 3.1, Figure 3.3 and Figure 10.3, and they are the same numbers
the report quotes in the abstract.

`make_cavity()` is the other nine. It reads `solution_fields.npz` from each of
the twenty-one run folders, which come to several hundred megabytes and are not
in this repository — the rendered figures are, in
[`06-lid-driven-cavity/figures/report/`](../06-lid-driven-cavity/figures/report/).

### `cavity_analysis.py` — every number in Chapters 10–12

```bash
python3 cavity_analysis.py /path/to/the/run/folder
```

`ψ_min` and vortex position on every grid, centreline errors against the
benchmark, the first-order Richardson extrapolation, the share of the cavity
turning the wrong way, and an independent check that re-solves the discrete
Poisson equation exactly for each saved vorticity field. Needs the run folders,
so it does not run from this repository either; it is here because it is the
definition of how each number was obtained.

Its header documents three corrections to the benchmark table itself:

- Ghia et al. print `u = −0.86636` at `Re = 3200, y = 0.4531` and
  `v = +0.03111` at `Re = 10000, y = 0.5`. Neither can be right; they are read
  as `−0.08664` and `−0.03111`. Excluding them instead changes no quoted number,
  and the script checks that.
- `v(Re = 400, x = 0.9063)`, printed `−0.23827`, is excluded from every
  comparison. It is the point marked `×` in Figure 11.5.

my own learning work, and nothing belonging to the group is published here
without Dr. Suman's approval.
